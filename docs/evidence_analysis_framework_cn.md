# 物理指导的结霜 Evidence 分析框架

## 1. 研究边界

本流程回答的是：哪些扣除正常工况后的内部状态，能够跨循环重复地领先性能恶化，并在运行时间、当前性能和工况之外提供独立信息。性能终点定义为持续 120 s 的 5%、10% 和 15% 退化，主终点为 10% 退化时刻 $T_{perf}$。

本流程不能从自然运行数据识别最优除霜时刻 $T^*$。只有主动改变除霜时机，并比较触发前损失、除霜消耗、供热中断和恢复损失后，才能讨论 $T^*$。

## 2. Evidence 决策链

| Gate | 必须回答的问题 | 核心证据 | 下一步决策 |
|---|---|---|---|
| G0 队列 | 哪些循环进入本次分析？ | Dataset 状态、稳定制热至除霜/结束的时长 | 当前仅作探索；正式研究需冻结准入协议 |
| G1 目标 | $T_{perf}$ 是否可稳定观测？ | 5/10/15% 事件、持续性、右删失、目标覆盖率 | 事件不稳则改为区间或阶段目标 |
| G2 正常参照 | 普通工况变化是否已被剥离？ | `actual - normal baseline` residual | 基线失败时禁止解释为霜致变化 |
| G3 物理关联 | 信号是否跨循环同向变化？ | signed effect、Theil-Sen slope、日期平衡汇总 | 形成候选霜状态或淘汰漂移量 |
| G4 提前性 | 信号是否先于 $T_{perf}$？ | $L=T_{perf}-T_{signal}$、中位数、Q25、正提前比例 | Q25 大于行动时延才支持预警 |
| G5 时间边界 | 5/10/20 min 哪些仍有信息？ | 同循环精确时间锚点、未来退化支持度 | 删除没有信息的远期窗口 |
| G6 独立信息 | 新状态是否超过已有信息？ | 留出日期/循环上的 M0→M3 MAE skill | 决定传感器、历史和模型复杂度 |
| G7 稳健性 | 证据能否跨日期保持？ | 日期平衡中位数、方向一致性、改进比例 | 决定统一规则或工况条件模型 |

M0 到 M3 使用完全相同的有效时间锚点：

$$
M_0=(t),\quad
M_1=(t,\text{工况},\text{当前性能}),\quad
M_2=(M_1,\text{候选 residual level}),\quad
M_3=(M_2,\text{候选 residual slope}).
$$

因此 `M2-M1` 只回答状态水平的条件增量，`M3-M2` 只回答历史动态的条件增量。若 M2 无增量，不需要为了形式完整引入复杂时序网络；若 M3 无增量，当前低维状态已经足够。

## 3. 统计与缺失规则

- 每个循环先独立计算，再先聚合到实验日期，最后跨日期取中位数，避免同一天循环较多而支配结论。
- 未来配对必须来自同一循环、同一结霜阶段和精确的 5/10/20 min 时间锚点。
- 被插补值不作为 observed evidence；关键事件缺口会中断持续性判断。
- 有除霜起点时在除霜前右删失；没有除霜起点但循环已结束时，在循环结束时右删失。
- 不可用结果保留明确状态和原因，不用插补或删除掩盖科学不可识别性。

## 4. 当前探索队列与未来正式准入

当前配置纳入 `valid` 和 `incomplete` 中严格大于 30 min 的循环。这样可以利用目前全部长循环寻找假设，但 `incomplete` 可能包含除霜状态缺口、非完整边界和未观察反事实，因此结果只能称为探索性证据。

未来 100+ 循环的正式准入至少应在看结果前冻结：完整边界要求、关键通道覆盖率、关键事件附近最大缺口、稳定基线可识别性、工况范围、传感器校准状态、相机角色与同步质量，以及同一设备/日期的独立单位定义。探索队列与验证队列必须分别报告，不能用正式准入反复筛到得到理想结论。

## 5. Figure contract

**核心结论：** 候选 residual 只有在 $T_{perf}$ 可评估、Q25 提前量为正，并且在留出日期/循环上增加预测 skill 时，才具备进入预警模型的证据。

**图型：** quantitative grid。`figure_4_readiness_decision` 以稳健提前量为主面板，配套展示状态水平/历史增量、5/10/20 min 决策状态和 $T_{perf}$ 可观察性。颜色只承担固定语义：蓝色为主要证据，青色为辅助状态，红色为历史增量或风险提示，灰色为不可用/未支持。

**导出：** Python/matplotlib 独占绘图；SVG 为主文件并保留 `<text>`，同时输出 PDF、PNG 和 600 dpi TIFF。

**审稿风险：** 当前最主要风险不是模型误差，而是探索队列包含 `incomplete`、事件右删失比例、日期数有限、残差基线可能不足，以及自然运行数据无法识别 $T^*$。任何结论都必须同时报告有效循环数和有效日期数。
