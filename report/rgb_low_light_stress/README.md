# 合成低光压力测试（阶段性结果）

## 目的与边界

现有实验只覆盖明亮与中等光照。本试验不声称验证真实低光泛化，只回答：冻结视觉表征和成本标签分类器在可解释的合成低光扰动下是否明显退化，以及在训练端加入相同类型的数据增强能否缓解退化。

## 最小试验设计

- 数据：15 个本地 cycle、3 个独立实验；测试图像共 414 张，按实验留一验证。
- 标签：沿用原始制热量成本函数导出的高置信度二分类标签，不改标签、不平滑。
- 机位：`front` 与全部六机位 pooled；下述数字报告 pooled 结果。
- 表征：冻结 DINOv2 ViT-S/14 与 EfficientNet-B0。
- 分类器：固定逻辑回归，只比较视觉表征和光照条件。
- 压力条件：原始光照、线性 0.6 倍亮度、gamma 1.8、gamma 2.2、gamma 2.2 加 shot/read noise、gamma 1.8 加暗角。
- 训练策略：仅原始光照；原始光照加 gamma、噪声和暗角增强。每轮增强训练严格排除被留出的实验。

## 阶段性发现

五种合成低光条件平均：

| 表征 | 仅原始训练 BA | 低光增强训练 BA | BA 改善 | 仅原始训练成本遗憾 | 增强后成本遗憾 |
|---|---:|---:|---:|---:|---:|
| DINOv2 | 0.747 | 0.769 | +0.022 | 0.00621 | 0.00524 |
| EfficientNet-B0 | 0.696 | 0.760 | +0.065 | 0.00713 | 0.00576 |

在 gamma 2.2 加传感器噪声条件下，增强相对仅原始训练使 DINOv2 BA 提高 0.046、EfficientNet-B0 提高 0.058。增强对原始光照的代价较小：DINOv2 BA 下降 0.011，EfficientNet-B0 下降 0.008。

当前最合理的判断是：DINOv2 的原始低光稳定性更好；EfficientNet 对照明更敏感，但从简单低光增强中获益更大。由于只有 3 个独立实验，个别条件的反常上升和宽置信区间不能解释为真实收益。全量云端 cycle 完成后必须按实验重复该检验，之后才能决定是否把低光增强纳入锁定模型。

## GitHub 方法取舍

- [Albumentations](https://github.com/albumentations-team/albumentations)：约 15.3k stars，MIT；提供亮度、gamma、噪声等成熟增强范式。
- [Kornia](https://github.com/kornia/kornia)：约 11.3k stars，Apache-2.0；提供可微分的强度增强。
- [Zero-DCE](https://github.com/Li-Chongyi/Zero-DCE)：约 1.1k stars；属于低光增强网络，会引入恢复模型自身偏差，本阶段不采用。

按 Ponytail 原则，本试验直接复用已安装的 PIL、NumPy 和 torchvision，只实现确定性压力条件，没有新增依赖或恢复网络。
