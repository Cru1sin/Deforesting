# 固定机位结霜图像表征调研与实验合同

检索日期：2026-08-20。目标不是寻找最大的通用视觉网络，而是寻找能够在本项目中冻结提取特征、适合固定机位纹理变化、可在一次 cycle 下载中完成推理，并可与现有 40 维颜色--梯度特征公平比较的模型。

## 锁定实验合同

三种表征使用完全相同的图像、成本标签、机位组和留一实验折：

1. `handcrafted`：34维颜色--梯度特征加6维机位独热编码；
2. `dinov2`：冻结 DINOv2 ViT-S/14 的384维图像特征；
3. `efficientnet`：冻结 EfficientNet-B0 的1,280维全局池化特征。

模型比较仍使用 logistic、随机森林、RBF-SVM、直方图梯度提升和单隐层 MLP。深度网络在这一阶段是冻结表征，不在相邻帧上端到端微调，避免把帧数误当作独立样本量。主验证单位是独立实验；学习曲线横轴为训练实验数，并同时记录 cycle 数、图片数和计算时间。

光照压力测试固定使用同一个 logistic 线性探针，只改变输入表征和测试图像：原图、60%亮度、140%亮度和60%对比度。报告平衡准确率、类别平衡误分类遗憾和原图--扰动图嵌入余弦相似度。该测试只衡量受控的光度扰动，不代表真实现场全部域偏移；最终判断仍以未见实验的原生图像表现为主。

## Ponytail 审阅

没有安装 `timm`、`open_clip`、`transformers`、Retinexformer或 imagecorruptions。DINOv2通过官方 PyTorch Hub 权重加载，EfficientNet-B0通过已安装的 torchvision 加载；两者与40维基线在同一次 cycle 物化过程中提取，图片随后按原流程清理。只有当全量结果显示光照扰动是主要失败源时，才增加 AugMix 或照明归一化。
