# 阶段三之一：RGB 成本标签

## 任务与输入

本步骤只读取图像元数据和阶段二的候选成本曲线，不下载、修改或删除云端图像。目标是把每张图像映射到同一循环、同一时刻的相对成本遗憾，形成可审计的分类标签。

当前有 45 个成本有效且包含结霜发展图像的循环；六个原始机位共有 57,213 条合格图像记录，其中 17,153 条在本地可用。

## 标签定义

对图像时间戳插值获得相对遗憾。候选域外图像不进入模型。遗憾不高于阈值的图像记为 `near_optimal`；其余图像再按最早成本最小点分为 `pre_optimal` 或 `post_optimal`。当前审计 1%、2%、5% 和 10% 四个阈值，不在独立实验验证前预先宣称某个阈值最优。

## 划分协议

训练、验证和测试以完整实验为单位，排序后按 3:1:1 分配；同一实验及其 cycle 不跨集合。禁止随机拆分相邻图像帧。1% 阈值在训练、验证和测试中分别有 17、5、7 个 cycle 提供 post-optimal 图像，因此可作为当前开发基线；2% 仅作为标签敏感性。

## 证据边界与下一步

本地 17,153 张图像足以打通工程链路，但 post-optimal 类只覆盖 3、1、4 个训练、验证和测试循环，不能作为发表级证据。下一步必须在全量云端 cycle 上复用完全相同的成本定义、实验级划分和阈值敏感性协议。
